# shooting-game

Cara permainan:
1. Buka aplikasi shooting game
2. Gerakkan roket dengan cara menekan panah kananmaupun kiri
3. Untuk menembak ufo, tekan tombol space
4. Hindari ufo agar nyawa tidak terkuras
5. Butuh 5 poin agar menang
6. Pada game terdapat obstacle asteroid yang harus dihindari

Itulah tutorial bermain shooting game!
